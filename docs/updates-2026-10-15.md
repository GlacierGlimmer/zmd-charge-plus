# 2026-10-15 开发记录

产品版本保持 v0.1.1；尚未发布。

- 增加可自定义的 Windows 全局快捷键，临时显示／隐藏全部 HUD。快捷键默认关闭；注册冲突保留原有组合键。
- 隐藏期间阻止自动呼出、预览和编辑高亮重新显示 HUD；新增实例继承隐藏状态；快速切换和保存应用中断保留最后请求的状态及配置。
- 内置帧率方案统一标注「需管理员身份运行」，中英文同步。
- 数据提示弹窗左下角增加「此数据不再提示」。只保存勾选时当前窗口已列出的变量；重启后继续生效。其他变量仍提示，未显示的新故障不会一并被屏蔽。
- 一般关闭弹窗仍仅确认当次故障；不同的新变量可以再次提示。无效表达式按具体方案及表达式区分。

新增提示行为同步到 Linux、macOS 和 Android。测试结果与平台限制见工作区 `.smoke/next-version-20261015` 及本轮交付说明。

## 第二批：快捷键动画与后续交互

- 快捷键独立选择完整／简洁显示动画，隐藏播放收回动画；快速反向操作取消旧动画并执行最后请求。
- 常驻轮播新增向上翻滚，窗口、胶囊及层级稳定；快速连续切换保持原地翻滚。
- Windows 新增 18 个原生媒体变量；无时间轴时保留不可用，超时和退出不会等待媒体服务。
- 增加可视化事件规则，支持阈值、变化、布尔边沿和独立冷却；默认不启用规则，不在首次采样或数据恢复时误触发。
- 热区可配置位置、大小、偏移和停留滑条，可选择每次呼出推进轮播。

翻滚、规则与热区同步到 Linux/macOS；媒体采集本轮为 Windows 功能。具体使用、来源和验证边界见 next-version.md。
