# Windows 设置导航与使用手册

2026-10-16 本地开发，产品版本仍为 v0.1.1。

## 页面结构

主选项卡顺序：显示与位置、HUD显示内容、数据管理、实验性功能、使用手册、关于。

“数据管理”下的子选项卡顺序：变量库、硬件数据、数据源配置。“HUD显示内容”保留方案配置与触发规则。移动的是同一套原有编辑控件，切换页面、切换语言后仍保留未保存的 HTTP 和 DeepSeek 输入，右上角“保存并应用”继续统一应用。

硬件数据的实时刷新仅在“数据管理 → 硬件数据”被选中时运行。变量库和硬件页共用运行时的硬件发现结果。

## 变量去重

发现有值的对应硬件项目后，变量库隐藏旧的重复硬件条目，包括相同的处理器型号与厂商、独立风扇、固件信息及 CPU/GPU 原始读数。旧变量的运行时读取和模板解析继续支持，已有方案和导入配置不需要迁移。

最高温度、核心平均温度、最大功率、主板最高温度与最高风扇读数属于汇总值，保留并标注“汇总”。来源、设备或测量含义不同的项目不合并。设备暂时离线时保留已发现的新变量定义，显示不可用读数。

## 使用手册

应用内置 14 章离线手册：快速开始、显示位置外观、方案内容、变量模板表达式、硬件驱动、数据源、轮播动画、快捷键热区、触发规则、时间网络帧率、媒体、多 HUD、维护、常见问题。

- 左侧章节目录和搜索可定位功能、变量名与中英文用法。
- 每章按小节卡片排版，顶部小节按钮直接滚动定位，底部可切换上一章/下一章。
- 配置步骤编号显示；模板与 HTTP JSON 示例单独排版，可复制。
- “打开对应设置”跳转到实际设置页；切换语言保留当前章节。
- 覆盖保存层级、显示/隐藏动画、变量与表达式语法、AIDA64、PawnIO、API、轮播、热区、事件规则、多 HUD 和按变量关闭数据提示。
