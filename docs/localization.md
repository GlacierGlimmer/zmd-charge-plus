# 语言目录、全局外观与平台范围（2026-10-18 开发源码）

设置顶部现在是带地球图标的 `Language / 当前语言中的“语言”` 按钮，点击进入独立的可搜索语言页面。列表显示语言原名与地区，保留“跟随系统”；其偏好保存为 `Auto`。明确选择的地区或书写系统会保留，例如 `zh-HK`、`en-GB`、`pt-PT`、`sr-Cyrl`。不支持的系统语言回退英语。

“全局字体大小和UI缩放”分别设置 75%–200% 的文字倍率和界面倍率，设置窗口与所有 HUD 共用。单个 HUD 的原有大小参数继续与全局 UI 倍率相乘。两项偏好立即保存，编辑器中未提交的配置、JSON 和密钥不随之提交。大倍率下保留滚动访问，HUD 按内容尺寸和屏幕边界适配。

## 目录与译文覆盖

根据 Mojang Java 26.3 稳定版的语言清单核对了 143 个语言选项，另外保留 ECP 的孟加拉语、乌尔都语和藏语，共 146 项。非官方、历史拼写和趣味语言也在目录中。下载的游戏语言资源仅作本地元数据核对，未放入源码仓库。

146 项均有离线包和基础导航。`reviewed-coverage.json` 将目录覆盖和正文覆盖分别记录：当前只有 44 套覆盖现有桌面消息键集合，102 套仍有高级文案回退；44 套中也有地区复用和趣味英语变体，不能据此声称全部自然语言已经完成审校。安卓专用长说明还有额外翻译缺口。罕见语言和构造语言的自行编写文字仍需进一步校订。

HTTP/JSON 内置注释说明提供简中与繁中，其他语言使用英语说明。变量键、格式槽、公式、JSON、URL、单位和用户文本保持原样。运行时不调用在线翻译服务。

## 平台与验证范围

Windows、Linux、macOS 使用相同的语言浏览页、设置导航和全局外观控件。硬件采集与系统权限遵循各自平台；PawnIO/AIDA64 仅在 Windows。Linux/macOS 手册给出原生接口说明，不要求安装 Windows 驱动。当前原生桌面构建没有媒体会话数据源时，手册明确标注不可用。Linux 全局快捷键使用 X11；纯 Wayland 会报告不支持，不能视为已经达到所有输入能力一致。

Android 使用同一语言目录及离线译文。自定义语言标签由应用内部解析，不冒充 Android 官方资源限定符。系统通知的排版和字号由 Android 控制；全局 HUD 字体/UI 设置作用于应用设置页和悬浮 HUD。移动端手册按实际控件和可用能力调整。

本轮已通过实际主题下的语言/缩放专项、原有 21 语言界面专项、离线包语法检查与安卓单元测试。托管编译通过不等于已在真实 macOS、Linux 桌面或安卓设备完成全部原生交互实测。`check_resources.py --complete` 会在存在正文缺口时失败，不能用基础目录通过替代完整翻译验收。

版本冻结为 Windows/Linux 0.1.2、macOS 0.1.4、Android v0.1.3/code4。源码同步不创建标签或 Releases。此前版本的说明与测试记录如下，不能当成本轮全部平台的验证结果。

# Windows 多语言

在设置顶部的语言下拉框选择语言，或选择“跟随系统”。本次包含 21 种语言：简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语、俄语、阿拉伯语、印地语、孟加拉语、乌尔都语、印度尼西亚语、越南语、泰语、土耳其语、意大利语、波斯语、藏语。

语言选择框始终显示“文/A”矢量图标，不依赖当前界面文字或字体。图标位于选择框内部，点击该区域也会展开语言菜单；悬停提示和辅助功能名称同时保留 `Language` 标识。RTL 界面中的图标也保持原有方向。

## 使用行为

- 选择语言立即生效并保存；其他尚未保存的设置、API Key、JSON 编辑保留在编辑器中，仍通过“保存并应用”提交。
- “跟随系统”持久化为 `Auto`，启动时根据 Windows 界面语言选择；不支持的语言回退英语。繁体地区与语言别名会归一化，例如 `zh-HK` → `zh-TW`、`en-GB` → `en-US`、`pt-PT` → `pt-BR`。
- 全新配置和重置默认值都使用 `Auto`。手动选择后保留所选语言；已有手动设置不会被后续系统语言覆盖。藏语 `bo`、`bo-IN` 和 `bo-CN` 均归一化为 `bo-CN`。
- 设置、变量说明、内置方案、数据警告和 14 章离线手册随语言切换。自定义方案文本、变量键、公式、设备原始名称、URL、路径、单位和 JSON 数据不作为界面文案改写。
- 阿拉伯语、乌尔都语、波斯语使用从右到左的界面；JSON、公式、数值等技术输入及代码示例仍从左到右显示。
- 页签统一使用相同字号和内边距；较长的主选项卡可以换行。HUD 配置和数据管理子选项卡使用一致的起始位置。
- 运行时只读随程序嵌入的 JSON 资源，不调用翻译服务，不需要联网下载语言包。
- HTTP/JSON 编辑框中的内置注释说明提供简体中文、繁体中文两版；其他界面语言统一使用英语版。切换语言时保持示例 JSON 结构一致，已填写的有效 JSON 不会因说明语言变化而重写。
- 藏文使用随包嵌入的 Noto Serif Tibetan 字形回退，覆盖藏文字母和组合元音；字体取自 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/notoseriftibetan)，许可证全文保留在 `NOTICE.md` 和 `Assets/Fonts/OFL-NotoSerifTibetan.txt`。不要求用户安装字体。

## 文案与手册资源

`Localization/<culture>.json` 以稳定的英语文案或格式字符串为键。格式化消息先翻译格式，再插入原参数；缺失或空的翻译回退到英语。中文仍保留既有原文。

`reviewed-core.json` 与 `reviewed-ui.txt` 保存统一校订的导航、常用控件、常见指标和关键权限/警告文案。`reviewed-ui-keys.json` 固定本轮补充界面文案的索引，`reviewed-ui-complete.txt` 保存逐语言翻译，`reviewed-status.txt` 保存运行时状态文案。藏语资源分别保存在 `reviewed-bo-CN.json` 和 `reviewed-bo-ui.txt`，由本地脚本统一组装。`manual.<culture>.json` 保存各自编写的 14 章指南，将步骤和说明分卡显示；示例直接复用源代码中的原始示例。简体中文、繁体中文、英语沿用完整的双语源手册。手册保留目录、搜索、前后章、章节定位、复制代码和跳转设置。

新增文本时须同时核对变量占位符、格式参数、术语、界面宽度和文字方向。资源覆盖和自动断言不能替代自然语言审校；低频硬件属性与专业描述后续仍可持续校订，不应声称已经过所有语言的母语人士审核。

## 本地检查

```powershell
dotnet build Tests/BugRegressionTests.csproj -c Release
dotnet run --project scripts/localization/catalog/LocaleTools.csproj -- . ../.smoke/localization-catalog
python scripts/localization/check_resources.py
dotnet run --project Tests/BugRegressionTests.csproj -c Release --no-build -- --localization
dotnet run --project Tests/BugRegressionTests.csproj -c Release --no-build
```

目录提取工具使用 .NET 10 SDK 自带的 Roslyn，读取源码及已经生成的测试程序集，不读取用户设置。先检查提取结果中的 `missing-xaml.txt` 和新消息，再用 `python scripts/localization/pack_resources.py --source <catalog.zh-CN.json>` 更新语言包。设置页面的说明、选项和状态必须有校订译文，不能把资源值等于英语原文视为翻译完成；生成时检查全部设置来源，测试实际页面可见文字。原始设备字段、协议与专业缩写保持原样，低频专业指标名称仍有后续校订空间。弃用的机器草稿不纳入包，维护阶段也不需要调用翻译服务。繁体转换使用 Windows 本地字符映射，并统一地区用语。

`--localization` 检查 21 种语言资源、格式参数、内置方案变量、原始 JSON 示例、实际窗口边界、RTL、语言持久化、未保存输入和两组子页签间距，并逐页检查显示、HUD、规则、变量库、硬件、数据源、多实例及关于页面的说明。设置 `ECP_LOCALIZATION_TEST_OUTPUT` 可保存窗口截图。开发时的 `ECP_LOCALIZATION_PREVIEW` 只用于缩小排查范围；最终验收须清除此变量，覆盖全部语言。
