# 2026-10-16 开发记录

产品版本保持 v0.1.1，尚未上传 Releases 或商店。

- 修复管理员身份仍无 CPU 温度时缺少 PawnIO 依赖的诊断与安装流程；新增官方安装入口和管理员重启，区分驱动缺失、权限不足、无法访问和需要重启。
- 不再把无法访问 CPU 底层寄存器时的零值显示为真实温度；修正多 CPU 温度和核心均值，以及主板 Super I/O/EC 子节点汇总。
- 新增「硬件数据」页：实际读数、名称/原始 ID 搜索、变量复制、连续刷新和本地诊断导出。
- 变量库开放全部可枚举硬件传感器与硬件属性，补充 SMBIOS 逐内存条、处理器、缓存、主板、BIOS 等字段及 CPUID 识别。
- 接入 AIDA64 官方共享内存、注册表和 WMI 导出，覆盖全部导出 ID 和文本字段；既有 CPU/主板/风扇变量可回退到对应共享传感器。

使用与覆盖边界见 [hardware-data.md](hardware-data.md)。未接入需要单独授权的 CPUID SDK。

同日设置整理：主选项卡按“显示与位置、HUD显示内容、数据管理、实验性功能、使用手册、关于”排序；数据管理按“变量库、硬件数据、数据源配置”排序。重复的旧硬件变量从库中移除，已有方案继续兼容，汇总指标单独标明。新增 14 章离线使用手册，带目录、搜索、小节定位、复制示例和设置跳转；详见 [settings-navigation.md](settings-navigation.md)。

同日多语言：Windows 加入 20 种语言选择与跟随系统，主导航、常用编辑控件、内置方案和关键警告采用校订文案。新增语言均有自行编写的 14 章离线指南，按步骤、说明和示例分卡排版。阿拉伯语、乌尔都语、波斯语使用 RTL，代码和技术输入保持 LTR。语言选择只保存自身，不提交其他未保存编辑。两组子选项卡保持相同字号、内边距和起始位置。低频硬件属性、长说明及部分辅助提示尚未逐条校订，明确回退英语；不发布不可靠的翻译草稿。参见 [localization.md](localization.md)。

多语言最终验证：20 种语言全部实际打开窗口，专项 101,714 项、数据警告专项 13 项、完整回归 443 项通过。中文按钮原文冲突及简繁往返均有专门回归，变量名、格式、单位、公式和 JSON 示例保留原样。仅本地导出 Windows x64 开发包，产品版本不变。

验证：380 项完整回归、最终 33 项硬件专项、12 项管理员实机检查通过。本机在获授权安装官方 PawnIO 2.2.0 后，CPU 温度连续采样可用；发现 393 个传感器及硬件信息项目。AIDA64 通过官方格式及实际 Windows 共享内存夹具验证，本机未运行真实 AIDA64，WMI 导出的端到端验收仍需有对应软件的环境。
